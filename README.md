### Task 1. Maximum Flow in a Logistics Network

This task models a logistics network using a directed graph and finds the maximum flow using the Edmonds–Karp algorithm.

**Technologies:**
- Python 3
- NetworkX
- Tabulate

Run:

```bash
python3 task1.py
```
